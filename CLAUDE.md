# Project rules for Claude

## Language

- **All documentation in this repository is written in English.** This includes the README, everything under `docs/`, code comments, commit messages, issues and pull request descriptions.
- Discussions with the team may take place in German. Anything that goes into the repository is written or translated into English.

## Documentation structure

- `docs/drafts/` – drafts and starting points for discussion. Mark each with a status line at the top.
